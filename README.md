# 눈물이 꽃이 된다 (Tears in Bloom)

p5.js로 만든 파티클 시스템 작품입니다.
흐느끼는 사람의 눈에서 떨어진 눈물이 땅에 닿은 자리에서 꽃이 되고,
그 꽃이 다시 꽃가루를 피워내는 과정을 하나의 바람이 관통합니다.

- 감상 주소: https://beemoisalive-debug.github.io/MyPartySystemPorking/

## 조작

| 입력 | 효과 |
|---|---|
| 마우스 좌우 이동 | 바람의 세기와 방향 |
| 화면 누르고 있기 | 눈물이 흘러나옴 (누르는 동안 계속) |
| ← → 방향키 | 바람 |
| R | 꽃밭 비우기 |

바람이 바뀌면 **눈물의 낙하 궤적**, **꽃 줄기가 휘는 방향**, **꽃가루의 흐름**이
동시에 달라집니다. 꽃이 피는 위치도 눈물이 떨어진 자리에서 결정됩니다.

## 구조

```
Wind .................. 외부 힘(바람). 모든 입자가 이 하나의 벡터를 공유
ParticleSystem ........ 입자를 관리하는 기본 시스템
  ├ TearSystem ........ 눈물 입자(TearDrop) 관리 — 눈 2개 = 시스템 2개
  ├ Garden ............ 꽃 입자(Bloom) 관리 — 눈물이 닿은 자리에 꽃을 심는다
  └ PollenField ....... 꽃가루 입자(Pollen) 관리 — 다 핀 꽃에서 나온다
```

| 파일 | 역할 |
|---|---|
| `Config.js` | 화면 크기, 땅 높이, 얼굴/눈 좌표 |
| `Wind.js` | 외부 힘(바람) |
| `ParticleSystem.js` | 입자 관리 기본 클래스 |
| `TearDrop.js` | 눈물 입자 + 눈물 시스템 |
| `Bloom.js` | 꽃 입자 (줄기 성장, 꽃잎 개화, 바람에 휘는 스프링) |
| `Garden.js` | 꽃밭 시스템 |
| `Pollen.js` | 꽃가루 입자 + 꽃가루 시스템 |
| `sketch.js` | setup / draw / 입력 처리 |

## 흐름

```
눈 → 눈물 → (중력 + 바람) → 땅에 닿음 → 그 자리에 꽃이 핀다
                                        → 다 핀 꽃이 꽃가루를 내보낸다
                                        → 꽃가루도 바람을 탄다
```

## 실행

정적 파일만으로 동작합니다. 별도 빌드가 필요 없습니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```
